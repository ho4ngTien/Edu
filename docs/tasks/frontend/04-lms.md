# Frontend Checklist: Module 04 - LMS (Learning Management)

**Trạng thái:** ⏳ Pending
**Tiến độ:** 0%

## Chế độ Học tập (Focus Mode) dành cho Học sinh
- [ ] Xây dựng Layout `app/(courses)/layout.tsx`: Loại bỏ Sidebar và Topbar rườm rà. Chỉ giữ lại logo và tên khóa học.
- [ ] Giao diện chia đôi: Cột trái (25%) hiển thị Cây bài giảng (Lesson Tree), Cột phải (75%) hiển thị Nội dung.
- [ ] Tích hợp PDF Viewer hoặc File Viewer cơ bản để học sinh đọc tài liệu trực tiếp trên Web.

## Giao/Nộp Bài tập (Assignments)
- [ ] UI cho Học sinh: Card hiển thị Bài tập (Tên, Hạn chót - Đếm ngược thời gian).
- [ ] Form nộp bài: Khu vực Dropzone (Kéo thả file) và ô Text Area để nhập lời nhắn. Xử lý UI tiến trình tải lên (Progress bar).
- [ ] UI cho Giáo viên: Bảng danh sách học sinh nộp bài, phân loại trạng thái (Đã nộp, Nộp muộn, Chưa nộp). Có nút tải file bài làm về máy.
