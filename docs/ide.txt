========================================================================
             HƯỚNG DẪN NHANH DỰ ÁN EDUIE - HỆ THỐNG LẬP TRÌNH TƯƠNG TÁC
========================================================================

Dự án "EduIDE" là giải pháp phần mềm giả lập môi trường phát triển tích hợp (IDE) học tập trực tuyến, cho phép biên dịch và chạy thử mã nguồn (HTML, CSS, JS, Java) trực tiếp trên trình duyệt, kết hợp với lộ trình học bài (Curriculum) có sẵn tiêu chí chấm điểm tự động.

------------------------------------------------------------------------
1. CẤU TRÚC THƯ MỤC CỐT LÕI (MONOREPO)
------------------------------------------------------------------------

* backend/            : Dự án máy chủ Spring Boot, Java 21.
  └─ src/main/java/com/edu/ide/module/
     ├─ workspace/    : Quản lý tệp tin và không gian làm việc học sinh.
     ├─ execution/    : Trình biên dịch mã Java cục bộ trên máy chủ.
     └─ curriculum/   : Lộ trình 4 bài học, so khớp từ khóa chấm điểm.
* frontend/           : Ứng dụng khách React, Vite, TypeScript.
  └─ src/features/
     ├─ workspace/    : Sơ đồ cây thư mục (File Tree) bên trái.
     ├─ editor/       : Trình soạn thảo văn bản chính (Monaco/Textarea).
     ├─ curriculum/   : Khung hướng dẫn bài học, gợi ý và nộp bài.
     ├─ terminal/     : Hiển thị nhật ký thực thi, lỗi biên dịch.
     └─ preview/      : Khung xem trước kết quả trực quan (iframe).
* infrastructure/     : Kịch bản khởi động và cấu hình ảo hóa Docker.
  ├─ run-dev.bat      : Kịch bản khởi chạy đồng thời backend + frontend lập trình.
  ├─ run-docker.bat   : Kịch bản build và khởi chạy thông qua Docker.
  └─ docker-compose.yml : Thiết lập mạng ảo và container hóa monorepo.
* docs/               : Thư mục chứa tài liệu đặc tả kiến trúc, API và luồng xử lý.

------------------------------------------------------------------------
2. HƯỚNG DẪN KHỞI CHẠY NHANH (QUICK START)
------------------------------------------------------------------------

Cách 1: Khởi chạy môi trường phát triển cục bộ (Khuyên dùng trên Windows)
  1. Mở cmd trong thư mục gốc dự án.
  2. Di chuyển vào infrastructure: "cd infrastructure"
  3. Gõ lệnh chạy: "run-dev.bat"
  4. Hệ thống sẽ tự động khởi động backend (8080), frontend (5173) và mở 
     trình duyệt tại: http://localhost:5173

Cách 2: Khởi chạy bằng Docker Compose
  1. Bật Docker Desktop trên máy tính.
  2. Mở cmd trong thư mục "infrastructure/".
  3. Gõ lệnh: "run-docker.bat" (hoặc chạy "docker-compose up --build -d").
  4. Truy cập giao diện tại: http://localhost:5173 (cổng phụ) hoặc http://localhost (cổng HTTP chuẩn).

------------------------------------------------------------------------
3. DANH SÁCH 4 BÀI HỌC HỌC TRÌNH (CURRICULUM LEVELS)
------------------------------------------------------------------------

* Bài học 1 (html-basics) : Cấu trúc Web cơ bản (HTML)
  - Tệp mục tiêu: index.html
  - Tiêu chí: Có thẻ h1, div chứa class="card", button chứa id="action-btn".
* Bài học 2 (css-styles)  : Trang trí giao diện (CSS)
  - Tệp mục tiêu: style.css
  - Tiêu chí: Có màu nền chuyển sắc (linear-gradient), bo góc (border-radius), hover.
* Bài học 3 (js-click)    : Tương tác người dùng (JavaScript)
  - Tệp mục tiêu: script.js
  - Tiêu chí: Đăng ký lắng nghe addEventListener('click'), in log console.log.
* Bài học 4 (java-loops)  : Thuật toán và cú pháp backend (Java)
  - Tệp mục tiêu: Main.java
  - Tiêu chí: Sử dụng vòng lặp (for/while), in màn hình System.out.println.

------------------------------------------------------------------------
4. CÁC CƠ CHẾ NỔI BẬT & BẢO MẬT HỆ THỐNG
------------------------------------------------------------------------

* Chống Directory Traversal: Hàm "resolveSafe" đảm bảo học sinh không thể 
  xóa hay sửa các tệp tin hệ thống nhạy cảm nằm ngoài thư mục "workspace/".
* Chống treo CPU do vòng lặp vô hạn: Trình biên dịch khống chế thời gian chạy
  của tiến trình con tối đa 5 giây. Hết 5 giây, tiến trình bị hủy cưỡng chế.
* Dọn dẹp đĩa cứng tự động: Khối lệnh try-finally bảo đảm thư mục UUID tạm 
  trong "temp_compile/" sẽ được dọn sạch hoàn toàn sau mỗi lượt chạy Java.
* Hiệu ứng ăn mừng: Sử dụng thư viện canvas-confetti để bắn pháo hoa liên tiếp
  trong 2.5 giây khi học sinh hoàn thành xuất sắc toàn bộ bài học.
